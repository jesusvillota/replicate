## Question and options

Should the goal also do either optional extension named in the README? Neither is needed for the core replication or for the final report.

- **Latest sample (footnote 32, p.38).** The paper says the main regression was extended to 2025 and the result holds. We would rebuild the panel with `--end latest` (most sources run to 2026: GSW to 2026-10-16, CRSP ETFs to 2026-07-31, MSCI to 2026-10-20) and rerun the core exhibits. Cost: one work task and one run task, no new data. The proxies stay cash-market proxies.
- **3:30 PM check (footnote 28).** The paper mentions an unreported check with 3:30 PM prices supplied by an asset manager. We would use tape-kit SpiderRock SPY 1-minute bars. They exist only from 2018 and only on the CEMFI PC. Cost: a `--manual` data-copy task for you, plus one work task and one run task. The result covers about 5 of the paper's 26 years and a different instrument, so it cannot confirm the paper's check.

Options:
1. **Neither.** TASK-030 runs at once and the goal ends with the 1997–2023 report.
2. **Latest sample only.**
3. **3:30 PM check only.**
4. **Both.**

If you choose 2, 3 or 4, the planner adds the tasks (and the manual data-copy task for option 3 or 4) and adds them as dependencies of TASK-030. TASK-030 stays blocked on this decision until you answer.

## Evidence

- Paper-notes §2 (D1) and §2 (note on intraday data), and §5.17 (listed as not replicable).
- `docs/data/sources.md` coverage columns for the end dates above.
- README, "Possible M-3 extensions".

## Recommendation

Option 2. The latest-sample check needs no new data, extends the evidence by about three years and tests whether the effect persists. The 3:30 PM check cannot reproduce the paper's check (different data, 2018 start, manual copy) and would not change any conclusion.
