## Question and options

Which daily series replace Bloomberg's continuous ES and TY futures excess returns (paper-notes §3.1, D1 and D2) in the main panel? Which pair serves as the robustness alternative?

Options. TASK-011 defines each candidate:

- **A. Cash proxies.** ES: SPY total return minus rf (E1), or `^SP500TR` minus rf (E2). TY: a GSW-curve bond return minus rf (T1, T2 or T3), or the CRSP 10-year fixed-term index minus rf (T4).
  - Covers 1997 on.
  - Total-return based.
  - The close times differ from futures.
  - T1 has longer duration than TY.
- **B. Public futures with roll repair** (E3/T6, Yahoo).
  - These are real futures prices.
  - They start in 2000-09, so 1997–2000 must be spliced from option A.
  - Roll repair adds noise.
- **C. WRDS futures** (E4/T7). Only if TASK-010 finds them. This is the closest match to the paper.

Planner's prior, before any evidence:
1. Choose C if it exists.
2. Otherwise choose A, with E1 for ES, and T3 or T4 for TY (whichever tracks the TY benchmark better).
3. Use B as the robustness pair.
