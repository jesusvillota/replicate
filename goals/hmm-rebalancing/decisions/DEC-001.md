## Question and options

Which daily series replace Bloomberg's continuous ES and TY futures excess returns (paper-notes §3.1, D1 and D2) in the main panel? Which pair serves as the robustness alternative?

Options. TASK-011 defines each candidate:

- **A. Cash proxies.** ES: SPY total return minus rf (E1), or `^SP500TR` minus rf (E2). TY: a GSW-curve bond return minus rf (T1, T2 or T3), or the CRSP 10-year fixed-term index minus rf (T4).
  - Covers 1997 on.
  - Total-return based.
  - The close times differ from futures.
  - T1 has longer duration than TY.
- **B. Public futures with roll repair** (E3/T6, Yahoo).
  - These are real futures prices.
  - They start in 2000-09, so 1997–2000 must be spliced from option A.
  - Roll repair adds noise.
- **C. WRDS futures** (E4/T7). Only if TASK-010 finds them. This is the closest match to the paper.

Planner's prior, before any evidence:
1. Choose C if it exists.
2. Otherwise choose A, with E1 for ES, and T3 or T4 for TY (whichever tracks the TY benchmark better).
3. Use B as the robustness pair.

## Recommendation

Use **E1/T3** for the main panel: CRSP SPY total return minus French daily RF,
and a GSW 6.5-year zero-coupon Treasury return minus the same RF. Use **E2/T2**
for the robustness panel: Yahoo S&P 500 total return minus RF, and the GSW
10-year par-bond return minus RF. This alternative changes both constructions.

Merged TASK-011 (PR #26) compares eight candidates and 15 pairs. E1/T3 has
correlation 0.9917 and annualized tracking error 2.8069% against clean Yahoo
futures returns on 4,839 days. E2/T2 has correlation 0.9810 and tracking error
4.5655%. Both pairs cover the study endpoints; missing bond sessions remain
explicit. No usable WRDS futures or fixed-term Treasury index is available.

Independent review also removed residual-jump exclusions from the benchmark.
With only calendar roll exclusions, E1/T3 still ranked first: correlation
0.990948 and tracking error 2.9243% on 4,846 common finite days. The original
filter improves apparent fit modestly but does not change the recommendation.

These remain proxies. Treasury duration is approximate, close times differ,
and the benchmark has no observations before September 2000. The recommended
robustness pair differs from the planner's initial Yahoo-futures splice because
it covers the full study without a splice. The report also documents that
splice as an optional later check. The owner must accept the final choice.
